# Glass Control для Kodi

Набор дополнений Kodi 21 в «стеклянном» стиле:

| Папка | Что это |
|---|---|
| `webinterface.glasscontrol` | Веб-интерфейс управления Kodi (медиатека, плеер, настройки, пульт, файлы) |
| `service.glasscontrol` | Серверная часть: файловый менеджер, источники, яркость, сброс медиатеки |
| `script.glassnp.patcher` | Патч скина Mimic-LR: вид «Сейчас играет» со стеклом и визуализатором |
| `repository.glasscontrol` | Шаблон репозитория Kodi (для автообновлений) |

## Установка

**Способ 1 — из репозитория (рекомендуется, автообновления):**
1. Скачайте `repository.glasscontrol-*.zip` со страницы [Releases](https://github.com/Stexible/glasscontrol-kodi/releases).
2. В Kodi: **Дополнения → Установить из zip-файла** → выберите скачанный файл.
3. Затем: **Дополнения → Установить из репозитория → Glass Control Repository** → установите:
   - Glass Control (веб-интерфейс)
   - Glass Control Backend (сервис, нужен для файлового менеджера и источников)
   - Mimic-LR Glass Now Playing (патч темы, опционально)
4. Обновления будут приходить автоматически.

**Способ 2 — из zip вручную:**
1. Скачайте нужные zip со страницы [Releases](https://github.com/Stexible/glasscontrol-kodi/releases).
2. Распакуйте в папку аддонов Kodi (`.../.kodi/addons/`) или установите через **Дополнения → Установить из zip-файла**.

Веб-интерфейс открывается в браузере: `http://<адрес-Kodi>:8080`. Для работы нужно включить Настройки → Службы → Управление → «Разрешить удалённое управление по HTTP». Для файлового менеджера и источников установите ещё и `service.glasscontrol`.

## Источники и медиатека
В разделе «Файлы» → «Источники» можно добавить любую папку (в том числе подпапку сетевой шары) и сразу выбрать для неё тип содержимого: фильмы, сериалы, музыкальные видео или «Не задавать». Для музыки каждая добавленная папка становится отдельным источником.

После добавления Glass Control сразу запускает сканирование этой папки. Перед каждым обновлением медиатеки источники и база проверяются автоматически: включается обход подпапок, добавляются недостающие строки источников в базу музыки, чинятся дубли путей.

Логины и пароли из пути источника переносятся в `passwords.xml`; в `sources.xml` остаётся чистый путь. Kodi читает список источников при запуске, поэтому после изменения списка перезапустите Kodi или перезагрузите профиль.

## Как выпустить новую версию
1. Внесите изменения в папки дополнений.
2. Поднимите `version` в `addon.xml` изменённого дополнения (иначе Kodi не увидит обновление).
3. `git commit`, затем `git tag v1.2.2 && git push --tags`.
4. GitHub Actions соберёт zip, приложит их к релизу и обновит репозиторий Kodi на GitHub Pages.

Локальная сборка: `python3 tools/build.py` → `dist/releases/*.zip`.
Сборка репозитория: `python3 tools/build.py --base-url https://ЛОГИН.github.io/ИМЯ_РЕПО` → `dist/site`.

## Однократная настройка GitHub
Settings → Pages → Build and deployment → Source: **GitHub Actions**.
