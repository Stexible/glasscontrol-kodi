# Glass Control — центр управления Kodi

Веб-интерфейс (`xbmc.webinterface`) в стиле стекла: пульт и «Сейчас играет», медиатека, файлы, дополнения, настройки, система. Для Kodi 21 «Omega» (JSON-RPC v13), удобен на телефоне и ПК.

## Установка
1. Kodi → Дополнения → Установить из zip-файла → `webinterface.glasscontrol-1.1.0.zip`. Для файлового менеджера и управления источниками дополнительно установите `service.glasscontrol-1.0.0.zip` (серверная часть) и перезапустите Kodi.
2. Настройки → Службы → Управление → включить «Разрешить удалённое управление по HTTP»; в «Веб-интерфейс» выбрать **Glass Control** (при необходимости задать порт, логин и пароль).
3. Для событий в реальном времени включить «Разрешить удалённое управление с других систем» (порт 9090). Без этого интерфейс работает через периодический опрос.
4. Открыть `http://<IP устройства>:8080`.

## Возможности
- Воспроизведение: пауза, перемотка, громкость, звук/субтитры, очередь, перестановка, OSD, мини-плеер на всех страницах.
- Медиатека: фильмы, сериалы, музыка (альбомы, исполнители, треки), клипы; фильтры, жанры, сортировка, поиск; отметки «просмотрено», удаление из медиатеки, сканирование/очистка.
- Файлы (источники, любые папки, дополнения), избранное, ТВ/радио/записи/таймеры (если есть PVR).
- Дополнения: список, включение/выключение, запуск, сведения.
- Настройки: все системные настройки Kodi (динамический редактор по схеме) и настройки скина.
- Пульт: D-pad, свайп-панель, ввод текста, быстрые переходы; система: сведения, питание, профили, уведомления, журнал kodi.log.

## Новое в 1.1
- Вкладки «Папки» в разделах медиатеки, проводник с копированием/переносом/переименованием/удалением (нужна серверная часть), источники с кнопками «Обновить»/«Удалить» и добавлением.
- Быстрое обновление медиатеки (только новые/изменённые файлы + очистка удалённых), индикатор процесса, обновление и очистка по разделам.
- Настройки: панель «Сохранить изменения», единицы измерения, переключатели вместо полей, отдельные страницы «Веб-сервер», «Сеть», «Оформление» (тема светлая/тёмная/авто, 6 акцентных цветов).
- «Сейчас играет»: переходы к исполнителю и альбому, без мерцания; в мини-плеере громкость, mute и стоп.
- Воспроизведение в браузере (звук и видео на этом устройстве), яркость и погашение экрана (через серверную часть), регистронезависимый поиск, группировка альбомов, кэш навигации.

## Ограничения Kodi
JSON-RPC не умеет устанавливать/удалять дополнения и менять их собственные настройки — для этого в интерфейсе есть кнопка открытия каталога на экране Kodi.
